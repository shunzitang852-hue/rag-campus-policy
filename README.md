# 基于 RAG 技术的高校政策知识问答系统

## 一、项目简介

本项目为本科毕业论文配套工程，论文题目为：

《基于RAG技术的高校政策知识问答系统构建与检索策略优化研究》

项目主要面向高校政策文档，完成政策文档采集、文档解析、文本清洗、文本切分、向量化存储、关键词检索、混合检索、问答生成和检索效果评估。

项目重点研究不同检索策略对高校政策知识问答效果的影响，包括：

* Dense 向量检索
* BM25 关键词检索
* Hybrid 混合检索
* 可选的重排序策略
* 不同 Chunk 切分参数
* Recall@K 等检索评价指标

## 四、项目目标

本项目的主要目标包括：

1. 建立高校政策文档数据集。
2. 实现 PDF 和 DOCX 政策文档解析。
3. 对政策文本进行清洗和规范化处理。
4. 研究不同 Chunk 切分策略对检索结果的影响。
5. 使用 Embedding 模型生成政策文本向量。
6. 使用 ChromaDB 建立向量数据库。
7. 实现 Dense、BM25 和 Hybrid 检索。
8. 构建高校政策测试问题集。
9. 使用 Recall@5 等指标评估检索效果。
10. 构建可演示的高校政策知识问答系统。
