# PPT 案例候选摘要

本文档只筛选下一阶段人工复核候选，不构成人工正确性结论，也不直接决定最终 PPT 案例。

## 成功案例候选

### HDU_IES_QA_018

- 问题：学生转学管理办法第二十九条中的主体责任和义务。
- 为什么适合 PPT：转学条件、办理依据和“转入学期开学前办理”的期限容易被老师快速理解。
- Extractive 的问题：三个版本均混入制度制定依据、纪律处分细则等内容，没有清楚组织学生条件、学校办理依据和时间要求。
- LLM 的改善点：按“学生”和“学校（学院）”组织内容，并保留转学条件、办理依据和时间要求。
- 指标：LLM Keyword/Evidence 为 `0.900000 / 1.000000`；三个 extractive 版本均为 `0.233333 / 0.600000`。
- 是否仍需人工确认：是，需核对“学校（学院）”这一主体归纳与第二十九条原文是否完全对应。

### HDU_IES_QA_039

- 问题：国家助学金评比办法第二条中的责任或义务。
- 为什么适合 PPT：4500 元与 2700 元两档资助标准直观，指标差异明显。
- Extractive 的问题：主要抽取相邻奖学金制度总则和体测条款，未突出第二条的资助对象与金额。
- LLM 的改善点：准确组织两档资助对象和金额，并指出该条没有明确规定责任或义务。
- 指标：LLM Keyword/Evidence 为 `0.866667 / 1.000000`；extractive 最佳仅为 `0.100000 / 0.333333`。
- 是否仍需人工确认：是。题干询问“责任或义务”，reference 却是资助对象和标准，需先确认 QA 口径。

推荐优先使用 Q018 作为成功案例候选。它的题干、Gold 和政策内容关系更直观；Q039 虽然数字更突出，但存在题干—reference 口径疑点，不宜在人工确认前作为主成功案例。

## 困难案例候选

### HDU_IES_QA_032

- 当前问题：题干询问第一条中主体的责任或义务；第一条正文主要说明制定目的和依据。LLM 回答无法确认责任或义务，而 reference 正是该制定目的文本。
- 可能原因：题干与 Gold 的语义口径、自动关键词指标设计、回答范围理解均可能影响结果；不能只归因于生成模型。
- 指标：LLM Keyword/Evidence 为 `0.066667 / 0.250000`；三个 extractive 版本均为 `0.966667 / 0.750000`。
- 为什么适合说明后续工作：能直观说明高词面覆盖不必然等于正确回答题意，也说明人工核验 QA 设计的重要性。

### HDU_IES_QA_011

- 当前问题：题干询问学生资助对象认定办法第一条中的责任或义务；第一条同样主要写制定目的和政策依据。
- 可能原因：LLM 按字面题意拒绝归纳责任，但自动指标按 reference 中的制定目的计算，导致覆盖率很低。
- 指标：LLM Keyword/Evidence 为 `0.066667 / 0.333333`；三个 extractive 版本均为 `0.733333 / 1.000000`。
- 为什么适合说明后续工作：可用于解释人工复核需同时审查检索、生成、问题设计和 Gold，而不能把低分直接等同于模型错误。

推荐优先使用 Q032 作为困难案例候选。问题、第一条原文和 LLM 拒答之间的关系清楚，适合说明自动指标的边界和后续人工复核必要性。
