# 8 页开题答辩 PPT 设计说明

## 基本规格

- 比例：16:9，13.333 × 7.5 英寸。
- 页数：8 页。
- 视觉风格：本科论文答辩、学术、简洁、低装饰。
- 背景：极浅灰 `#F7F9FC`。
- 正文：深蓝灰 `#314155`；标题 `#182230`。
- 主强调色：深青色 `#155E75`，辅助青色 `#0E7490`。
- 基线图表颜色：低饱和蓝灰 `#A8B4C2`。
- 字体：微软雅黑；图表、标题、正文和备注统一使用可稳定显示中文的字体。
- 字号：页标题约 30 pt，正文以 18 pt 为主，重要数字约 34–38 pt；脚注与页码仅作为辅助信息。

## 版式逻辑

- 第1页使用大留白和左侧强调线，保持封面极简。
- 第2页采用左右对照，底部用可编辑流程框说明 RAG 的必要性。
- 第3页使用四列平铺研究内容，底部突出核心研究变量。
- 第4页左侧展示数据规模，右侧展示评价指标，并以小型流程串联实验设计。
- 第5页使用 PowerPoint 原生 Shape 与 Connector 构建两行技术路线，Chunking 与 Retrieval 使用主强调色。
- 第6页左侧解释三类检索，右侧展示原生分组柱状图，底部固定最终方案。
- 第7页上方使用两张原生柱状图，下方并列 Q018 与 Q032 两个案例。Generative RAG 使用主强调色，Extractive baseline 使用蓝灰色。
- 第8页左右分栏，左侧列已完成事项，右侧列后续工作与研究特点。

## 图表说明

### 第6页检索指标图

- 类型：PowerPoint 原生可编辑分组柱状图。
- 分类：BM25、Dense、Hybrid。
- 系列：Recall@5、MRR@5。
- Y 轴：0–1，主刻度 0.2，避免夸大差异。
- 数值：BM25 0.9500 / 0.8708；Dense 1.0000 / 0.9833；Hybrid 1.0000 / 1.0000。
- 公平性：三组结果均为 fixed_length、Top-K=5、40 题的 normalized 正式实验。

### 第7页 RAG 指标图

- 类型：两张 PowerPoint 原生可编辑柱状图。
- 图一：Keyword overlap，四组数值为 0.5433、0.5733、0.5467、0.7033。
- 图二：Evidence overlap，四组数值为 0.7658、0.7929、0.8721、0.8979。
- Y 轴：0–1，主刻度 0.2。
- 颜色：Generative RAG 使用强调色，三组 Extractive baseline 使用相同低强调度色。

## 技术路线图说明

- 所有节点和箭头均为 PowerPoint 原生可编辑对象，不使用截图。
- 第一行从政策原文依次进入清洗、切分、检索、Top-5 证据和上下文构建。
- 第二行从 DeepSeek 生成进入 Answer + Citation，再进入自动评价与人工复核。
- 引用明确标注为由 Retriever metadata 程序化生成。
