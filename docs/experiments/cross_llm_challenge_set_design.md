# 跨模型 Challenge / Stress Test 设计（未运行）

论文：《基于RAG技术的高校政策知识问答系统构建与检索策略优化研究》。

## 动机与边界

用户报告原40题的 DeepSeek 两模型人工评分存在天花板效应。
补充实验拟提高问题的条件复杂度和干扰程度，不修改原40 QA、
Frozen Evidence、人工评分或任何既有实验。此文件只给设计；
没有创建新的正式问题/答案、没有检索、没有 API 调用，也没有新实验指标。

## 计划16题

| 问题类型 | 数量 | 设计要求 |
|---|---:|---|
| 多条件资格判断 | 2 | 同时满足两个以上条件，并要求分别解释 |
| 否定条件与不适用情形 | 2 | 区分没有资格与证据未说明 |
| 例外条款 | 2 | 一般规则与例外同时出现在证据中 |
| 跨条款组合 | 2 | 组合两条以上规定，避免单条摘抄即可作答 |
| 时间边界 | 2 | 截止、起算、期限与边界值判断 |
| 数值限制 | 2 | 区分至少/超过/不超过，并明确单位 |
| 身份条件与近似政策 | 2 | 相似规定对不同身份适用 |
| 相似干扰与证据不足 | 2 | 近似条款作干扰；正确回答应指出证据不足 |

所有题目须先从项目已核验政策正文选定真实条款，记录来源、位置、
版本、适用范围和逐条 reference evidence。不能根据此类型表编造政策内容。
问题独立编号，禁止复用原40题 ID；由人工检查不存在歧义或答案泄漏。

## 实验控制

先固定 challenge questions 与单独的 Frozen Evidence/manifest。
同一挑战题对三个模型使用相同 question/context/prompt，固定证据顺序，
逐题计算 context/prompt SHA-256。至少保留原 top_k=5 和
policy_grounded_qa_v1；若需改变检索或 prompt，必须另立实验并记录，
不能并入当前原40题比较。所有 provider 配置及 reasoning 行为如实记录。

三个模型的正式 challenge 请求需另获用户授权；不重跑原40题。
在题目设计完成前，不声称全部难题可以由同一 top-5 证据充分回答。

## 评价与统计计划

保留 correctness 0/1/2、faithfulness 0/1/2、completeness 0/1/2、
hallucination 0/1，沿用原评分定义。额外记录边界条件遗漏、
例外误用和不恰当肯定作为 review_note 分类，不擅自改主评分量表。
独立匿名化、独立盲评，原40题与challenge分别汇报，不合并总均分。
小样本以配对描述、逐题错误分析为主；如使用检验，预先记录方法、
零差值处理及多重比较策略。没有实际评分前不生成统计结果。
