# 杭州电子科技大学政策文件人工核验清单

本清单用于核验第一版杭州电子科技大学普通全日制本科生校级政策数据集。每份候选政策文件进入正式数据集前，都应完成以下人工核验。

## 一、来源核验

- [ ] 是否来自杭州电子科技大学官方域名
- [ ] 发布部门是否明确
- [ ] 是否记录原始发布页
- [ ] 是否记录下载日期
- [ ] 网页正文与附件标题是否一致

## 二、文件基本信息核验

- [ ] 文件标题是否完整
- [ ] 文号是否存在
- [ ] 发布日期是否明确
- [ ] 生效日期是否明确
- [ ] 是否出现废止、修订或替代说明
- [ ] 是否适用于普通全日制本科生
- [ ] 是否属于当前九类政策范围

## 三、下载文件核验

- [ ] 下载文件是否完整
- [ ] PDF是否可正常打开
- [ ] PDF页数是否正常
- [ ] 是否具有文本层
- [ ] 是否存在扫描件
- [ ] 是否已计算SHA-256哈希

## 四、版本与重复核验

- [ ] 是否存在重复文件
- [ ] 是否存在新旧版本冲突
- [ ] 是否记录替代文件或新版文件说明
- [ ] 是否确认本地文件命名符合规范

## 五、最终确认

- [ ] 是否经过人工确认
- [ ] 是否已填写 `policy_metadata_template.csv` 中所有可确认字段
- [ ] 无法确认的字段是否已在 `verification_notes` 中说明
- [ ] 是否未根据网页更新时间推断政策生效日期
- [ ] 是否未将新闻稿、搜索引擎摘要或非官方转载作为正式政策正文
